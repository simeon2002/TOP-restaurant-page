# Restaurant Page Project

A fully dynamically rendered restaurant site in Vanilla JS

## Mistakes

- Should have used `#content` container for the home screen instead of adding another wrapper... This is what I have done for the other dynamically rendered pages.
- I extracted a bit too much functionality into a `utils.js` module I think.

## Learning takeaways

- Practice on using DOM to manipulate and dynamically render pages. `index.js` as the orchestrator and each page as a separate `.js` module file
